Import, edit and export

  1. Add video, audio or images to the project bin, or choose Select Media in the AI assistant.
  2. Drag media to the timeline. Drag clip edges to trim, or split a clip before moving its parts. Linked picture and sound move together.
  3. Play the timeline in the project monitor to check picture, subtitles and sound.
  4. Save the project for future edits. For delivery, use Export in the AI assistant to make an MP4, or use the editor's Render dialog to choose the format and range.

Open an existing project through File → Open. Keep its source media and relink any files you move.

Edit with language

Choose Connect AI in the assistant to configure Codex, a compatible API, or local Ollama, or to get the WorkBuddy MCP configuration. Cloud providers use your own account and quota. The manual timeline works without an AI account.

After importing media, try “Join the clips in order, keep the original sound, and split the first clip at two seconds.” Review the timeline, describe further changes, or use Undo.

For a template, try “Make a travel photo story from these three photos, three seconds per photo.” Speech captions and local masking require the relevant models to be installed separately.

Image and video tools

Describe the treatment and output, for example “Lightly smooth the skin, keep its texture, and export a PNG.” For a cartoon overlay, ask for tracking on one front-facing person and say whether to keep the original audio. Review the whole result, especially when the face turns or is covered.

The video-generation panel offers local photo motion and online generation. Online video and voiceover availability and quota depend on the selected provider. Import the resulting media into the timeline to edit it.

Effects

Select a timeline clip and drag an item from the Effects list onto it, or double-click the effect. Use the effect stack to adjust settings, add keyframes or temporarily disable the effect. Preview the result before exporting.

Transitions and compositing

Add a mix between adjacent clips and adjust its duration to change the overlap. To combine tracks, place a composition over the desired range and check the target track and timing.

Motion tracking models

Start with a tracker that needs no additional model and draw a box around the subject. For DaSIAM or Nano, use the effect panel's model folder and place the relevant ONNX files there, then select the algorithm again. Nano also requires OpenCV 4.7 or later.

Review the tracking after analysis. If the subject exits the frame, is covered or moves quickly, shorten the range or select the subject again.

Jog/Shuttle devices

Check that the operating system recognizes the controller. Then open Settings → Configure PhraseSplice and find the JogShuttle page. If supported, enable the device and assign button actions. If the page reports it is unavailable, check the driver and whether the current build supports your device.

Troubleshooting

  • Installation fails: Use a writable local folder with an ASCII path. If a checksum fails, check the network and remove only the cache file named by the error before retrying.
  • Import or export fails: Try a short H.264/AAC MP4. Check source media links, write permissions and available disk space.
  • The assistant misses a request: Check the connection, selected model and tool-call support. Start with a short clip and a single instruction, then inspect the timeline.
